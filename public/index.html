Fonctionnement Universel

Les skills s'installent dans vos dépôts existants sans modifier votre environnement.

1

Exécutez la commande

Dans le dossier de votre projet web ou mobile (React, Vue, Next.js, Flutter, React Native, Laravel...), lancez la commande d'installation.

2

Fichiers autonomes

Le standard est téléchargé dans .agents/skills/<skill>/SKILL.md. Il est versionné avec votre code dans Git.

3

L'IA applique les règles

Votre assistant IA (Antigravity, Cursor, Claude Code, Codex) lit nativement ces règles et génère des interfaces sobres et du code sécurisé.

Foire Aux Questions

Principes et utilisation de DevStandard.

Pourquoi pas de fond sombre violet ou d'effets visuels IA ?

Les dégradés violets et néons sont des marqueurs typiques du contenu généré artificiellement sans considération ergonomique. Les portails d'État (ANIP, RAVIP, service-public.bj), les applications bancaires et les produits d'envergure utilisent un fond blanc ou très clair et des icônes vectorielles sobres pour maximiser la confiance, la lisibilité et le confort visuel.

Est-ce compatible avec les applications mobiles (React Native, Flutter, Swift, Kotlin) ?

Oui, absolument. Les skills intègrent les spécifications pour mobiles : cibles tactiles de 44x44pt (iOS) et 48x48dp (Android), gestion des zones sûres (*Safe Areas*), et composants adaptés à une manipulation à une main (*Bottom Sheets*).

Dois-je commiter le dossier .agents/skills/ dans mon dépôt Git ?

Oui. Commiter ces fichiers garantit que n'importe quel développeur ou n'importe quelle IA intervenant sur le projet respectera strictement la même charte d'ingénierie.
